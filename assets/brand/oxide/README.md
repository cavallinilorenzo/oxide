# Oxide brand mark

The selected **Strati** direction represents Oxide's parallel agent workspaces as three balanced, centered layers.

## Palette

| Color | Hex | Use |
| --- | --- | --- |
| Midnight blue | `#14234A` | Wordmark, top layer, app icon background |
| Cobalt blue | `#4F83F3` | Middle layer and primary accent |
| Ice blue | `#9DBFFF` | Bottom layer and light accent |

## Files

- `oxide-logo.svg`: horizontal mark and wordmark on a transparent background.
- `oxide-mark.svg`: standalone mark on a transparent background.
- `oxide-app-icon.svg`: square app icon artwork used to generate the Tauri platform icons.
- `png/mark/`: transparent mark exports at 16, 32, 64, 128, 256, 512, and 1024 px.
- `png/logo/`: transparent horizontal logo exports at 400×96, 800×192, and 1600×384 px.
- `png/app-icon/`: square app icon exports at 128, 256, 512, and 1024 px.
- `icon.icns`, `icon.ico`, and `icon.png`: generated platform icon formats in `crates/oxide-app/icons/`.

The SVG files are the editable vector masters. PNG exports use transparent backgrounds except for the square app icon.

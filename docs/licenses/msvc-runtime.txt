Microsoft Visual C++ Runtime Notice
===================================

The Windows dictation workers (oxide-vulkan-worker.exe, oxide-cuda-worker.exe)
are built with Microsoft Visual C++. When they import the Visual C++ runtime,
the installer places the imported runtime DLLs, unmodified, beside them
(app-local deployment), for example:
- vcruntime140.dll
- vcruntime140_1.dll
- msvcp140.dll

10 and later and is not redistributed.

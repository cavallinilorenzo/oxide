Di chi è un terminale? PROTOTIPO · da buttare · ticket #272

La domanda. Quando apri il terminale in Oxide, quella shell appartiene a chi? Al Thread (la conversazione), alla cartella di lavoro (checkout: la cartella principale del progetto, oppure il worktree di un Board Thread) o al Progetto?
Cambia cosa succede quando cambi Thread, crei un Board Thread, cancelli un Thread e quando l'agente lancia un comando.
Come usarlo (3 passi)
  1. Scegli un percorso guidato qui sotto (parti dal 3 · Cancellare un Thread) e premi i pulsanti blu in ordine.
  2. Guarda il riquadro «Cosa è appena successo» e il terminale nero dentro l'app finta.
  3. Senza ricominciare, cambia opzione (A, B, C, D) nei pulsanti in alto: la stessa sequenza viene rigiocata con l'altra regola e vedi la differenza. La tabella in fondo li confronta tutti insieme.
Le 4 opzioni:
  • A · per Thread (com'è oggi il pannello in basso): ogni Thread ha la sua shell, anche se due Thread lavorano nella stessa cartella.
  • B · per cartella di lavoro: una sola shell per cartella. Tutti i Thread della chat condividono quella della cartella principale; ogni Board Thread ha la sua nel proprio worktree.
  • D · come B ma con più tab: ogni cartella può avere più tab; ogni tab riporta il nome del Thread che l'ha aperta.
  • C · per Progetto: una sola barra di tab per tutto il progetto, a prescindere dal Thread.

Come decidere: 4 domande
  1. Due chat sulla stessa cartella: vuoi la stessa shell o due diverse? (percorso 1) Se un server di sviluppo avviato in una chat deve essere visibile nell'altra → B/D/C. Se vuoi isolamento totale → A.
  2. Quando crei un Board Thread, il terminale deve già trovarsi nel suo worktree? (percorso 2) A/B/D sì. C no: resti nella shell vecchia e serve un nuovo tab (compare l'avviso ⚠).
  3. Cancellando un Thread, il server di sviluppo deve morire? (percorso 3) A: sempre. B/D/C: solo se sparisce il worktree (Board Thread); per una chat la shell resta.
  4. Un solo terminale per cartella, o più tab? B è più semplice; D permette più shell nella stessa cartella (es. server + test).
I comandi dell'agente (percorso 4) sono uguali in tutte le opzioni: restano blocchi comando nella chat e non toccano mai le shell dell'utente.
Consiglio di Claude: D, partendo con un solo tab (cioè B). Se preferisci la versione più semplice, B.
